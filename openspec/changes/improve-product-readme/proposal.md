# Proposal: Improve Product README

## Why

当前 README 先展示协议、部署和 IPC 等实现细节，更像开发记录，首次访问者难以快速理解
Pijoo 解决什么问题、如何体验以及当前是否适合使用。

## What Changes

- 以现有品牌图、产品价值和下载入口组成仓库首页首屏。
- 提供英文主 README 与完整简体中文 README，并在顶部互相切换。
- 明确 Codex 已支持，Claude Code 与 Cursor 为 coming soon。
- 同步路线图与状态文档，避免 coming soon 与既有 Host 计划冲突。
- 用用户语言说明协作方式、核心能力、安装流程、隐私边界和 Beta 状态。
- 欢迎 Issue 与 Pull Request，并给出最小贡献边界。
- 保留开发命令，但把详细构建、运维与实现说明收敛到已有文档。

## Non-goals

- 改变产品能力、发布版本或稳定性口径。
- 新增官网、截图、演示视频或营销依赖。
