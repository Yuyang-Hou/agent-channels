# Proposal: Rename GitHub Repository to Pijoo

## Why

产品已经命名为 Pijoo，但公开 GitHub 仓库仍使用旧工作名称 `agent-channels`，影响项目识别，
且 App 自动更新仍硬编码旧仓库地址。

## What Changes

- 将 GitHub 仓库改名为 `Yuyang-Hou/pijoo`。
- 同步 App Release API、当前文档链接和本地 Git remote。

## Non-goals

- 重命名本机工作目录、历史分支或历史产物。
- 修改 Railway 服务、域名或 RogerThat npm 包名。
